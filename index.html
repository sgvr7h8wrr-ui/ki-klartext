📚 KI-Wörterbuch

Prompt

Deine Anweisung oder Frage an eine KI.

Modell

Ein KI-System, das Muster aus Trainingsdaten gelernt hat.

Halluzination

Eine plausibel klingende, aber falsche KI-Aussage.

Generative KI

KI, die neue Inhalte wie Texte, Bilder oder Code erzeugt.

Token

Ein Textbaustein, mit dem Sprachmodelle arbeiten.

Kontext

Zusätzliche Informationen, die der KI bei deiner Aufgabe helfen.
