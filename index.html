ℹ️ Informationen zu KI Klartext

Über das Projekt

KI Klartext ist ein privates, kostenloses und nicht kommerzielles Lernprojekt über künstliche Intelligenz. Die Inhalte dienen der allgemeinen Bildung, werden laufend weiterentwickelt und können Fehler enthalten. Bei wichtigen Entscheidungen bitte verlässliche Quellen und Fachleute hinzuziehen.

Der KI-Führerschein ist ein spielerisches Teilnahmezertifikat von KI Klartext und keine staatlich oder behördlich anerkannte Qualifikation.

Datenschutzhinweise

Diese statische Website wird über GitHub Pages bereitgestellt. GitHub protokolliert beim Besuch IP-Adressen zu Sicherheitszwecken. Weitere Informationen: GitHub Pages und GitHub-Datenschutzerklärung.

Lernfortschritt und Erfahrungspunkte werden im lokalen Speicher deines Browsers (localStorage) gespeichert. Sie werden durch diese Website nicht an einen eigenen Server übertragen. Du kannst diese Daten durch Löschen der Website-Daten im Browser entfernen. Für das Zertifikat eingegebene Namen werden nur im Browser verarbeitet. Es gibt keine Registrierung, keine eigene Besucheranalyse und keine Werbe-Cookies im Seitencode.

Bei Klick auf externe Tool-Links gelten die Datenschutzregeln der jeweiligen Anbieter. Die Angaben sind eine Vorlage und müssen bei technischen Änderungen überprüft werden.
